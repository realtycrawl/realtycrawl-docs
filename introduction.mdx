## Check coverage first

The inventory contains 200 researched platforms. Research coverage and defined API operations do not imply live availability. Read [coverage and evidence](/coverage), then check the current [capabilities endpoint](https://realtycrawl.dev/v1/meta/capabilities) for your source, operation, and country.

## Keep the evidence

A listing is a source observation, not a verified property identity or transaction. Preserve the complete response envelope, source URLs, observation times, units, unknown values, and warnings. See the [response schema](/response-schema).

## Choose your integration

Use the [REST API](/api-reference), [MCP tools](/mcp-guide), or [installable agent skill](/agent-skills). All three use the same API keys, capability boundaries, and credit accounting. Create a key in the [dashboard](https://realtycrawl.dev/dashboard/api-keys).
