---
title: "Resolve a listing URL or source ID"
openapi: "POST /v1/listings/resolve"
---

<Note>Check [live capabilities](https://realtycrawl.dev/v1/meta/capabilities) for the exact source, operation and country. Native detail availability is distinct from search and stored-read support. Documentation-backed beta bindings are described in [coverage](/coverage); preserve their evidence level and warnings.</Note>

A successful resolution returns a matched source listing and saves an account-owned listing observation for 24 hours. For Redfin, use the candidate's `source.native_id` with `GET /v1/redfin/listings/{native_id}` for a subsequent fresh detail lookup using the same account. The URL's `/home/` number identifies a property and is distinct from that listing ID.

Read the saved listing or its media using the candidate's opaque `id` through `GET /v1/listings/{listing_id}` and `GET /v1/listings/{listing_id}/media`. Source resolution costs 50 credits when successful; retained reads cost 1 credit and idempotent replays are free. Estimates, complete source history, contacts and current availability are not implied by a match.
