Read this account’s unexpired NYC PLUTO tax-lot property observation for1 credit. Requires returned property_id;24h retention. Property type parcel; source BBL reference. Borough-level location only; owner/contact/address/geometry omitted. Building year is source approximate and normalized only for single-building parcels; source units are tax attributes, not available inventory. No fresh source fetch, title, ownership or historical identity verification.

<Note>Check [live capabilities](https://realtycrawl.dev/v1/meta/capabilities?platform=nyc_pluto). Independent wrapper for NYC Open Data. Existing idempotency replay remains a prior snapshot and can outlive 24h selector retention.</Note>
