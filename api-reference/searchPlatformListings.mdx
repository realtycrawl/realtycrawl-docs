## Marketplace apartment observations

Facebook Marketplace supports one source-order apartment rental advertisement in a fixed 10 km circle centered on 40.75, -73.98. Cities may be in New York or New Jersey. Use this request body for platform search:

```json
{
  "transaction": "rent",
  "location": {
    "kind": "source_region",
    "platform": "facebook_marketplace",
    "country": "US",
    "region_id": "manhattan-centered-10km-apartment-rental-advertisements"
  },
  "limit": 1
}
```

For unified search, add `"platforms": ["facebook_marketplace"]`. The provider query uses fixed raw amount bounds of 500–6,000 USD. These do not establish recurring rent and are not supported customer price filters. Unsupported filters, sale, cursors or larger pages fail before source access.

Source property category, unit details/counts, canonical listing/share identity and actual item distance must agree. Numeric prices, billing period, deposit basis, availability, exact item location, contacts, photos and source update time are unknown or omitted. A source product ID is not assumed to be the native listing ID. This observation does not establish complete inventory or housing availability.

The four accepted source operations are platform search, unified search, retained account-owned listing and stored media. Media is an empty array for this source. Native-ID detail, resolution and listing history remain unavailable. Fresh searches cost 50 credits, retained reads 1, errors and prior-response replay 0. Account selectors expire after 24 hours; existing seven-day replay snapshots can outlive selector retention.

## Zillow search billing

Zillow costs 3 credits per returned listing. The default limit is 10. Reserve 3 times the requested limit; unused credits are refunded. Ten requested listings reserve 30 credits, while three returned listings cost 9 credits. A successful empty Zillow result costs zero. Other platforms cost 50 credits per successful source crawl. Unified requests combine platform reservations and refund failed platforms. Read X-Credits-Used for the final charge.


## Zillow filters and modes

Zillow accepts contiguous-US location.bbox, sale/rent transactions, active status, or transaction sale with status ["sold"]. Price bounds require USD (one_time sale or month rent); bedrooms use integer bounds, bathrooms numeric bounds, and area uses living sqft. Supported property types include single_family, condo, townhouse, multi_family, manufactured, land and apartment. Sort supports source_order, price_asc, price_desc and newest. Limit remains 1–100. Cursor, listed_since, include and property grouping remain unsupported.

Expanded selectors use provider documentation and offline tests. Preserve DOCUMENTED_SOURCE_BETA warnings; earlier live evidence establishes sale plus bounding box only. Other platforms retain source-specific restrictions. Native URLs in source_filters.zillow.search_url must contain a validated searchQueryState matching location.bbox and requested mode. Explicit normalized bounds, types and sort take precedence over corresponding native filter families.

```json
{"location":{"kind":"bbox","bbox":[-97.82,30.2,-97.65,30.35]},"transaction":"sale","price":{"min":200000,"max":900000,"currency":"USD"},"bedrooms":{"min":2},"property_types":["single_family"],"sort":"price_asc","limit":10}
```

For unified search add "platforms":["zillow"]. Response options fields and format belong in the URL query, not the JSON body. CSV/NDJSON contain data records; JSON retains meta. Response shaping does not change source cost or completeness.

## Source URL filter contracts

Redfin supports condo-only filtering with the existing US ZIP selector. Domain supports exact 1–3 bedrooms (min=max), apartment type and native price ordering in Sydney NSW 2000 rent mode. Property24 supports positive integer ZAR price bounds, minimum bedrooms 1–5 and one documented type within its existing source-area path. Unsupported bounds are rejected before collection; source scopes, result limits and spending ceilings stay in force. These mappings have documentation and offline-test evidence, not new live acceptance.
