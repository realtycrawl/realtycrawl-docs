## Marketplace retained observations

Facebook Marketplace supports account-owned 24-hour listing observations from its fixed Manhattan-centered 10 km apartment-rental circle. Numeric prices, billing period and availability remain unknown; exact item location and contacts are omitted. Stored media returns an empty array for this source. Native detail, resolution and history are unavailable. A successful stored read costs 1 credit; failures and prior-response replay 0. This read does not issue a source request.
