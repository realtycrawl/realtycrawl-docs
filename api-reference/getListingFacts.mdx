---
title: "Read property facts and virtual tours"
openapi: "GET /v1/listings/{listing_id}/facts"
---

Read a saved listing’s explicit property facts, normalized property values, price context and source-supplied features. Supported source sections vary; missing information remains null or unavailable. Search observations are not represented as full detail collection.

Facts are retained for 24 hours and cost one credit to read. This operation makes no fresh source call. Rightmove tenure, living costs, floor plans and stations, Idealista amenities and parking, and other explicit normalized source features can appear in details where supplied.
