---
title: "Read tax-assessed values"
openapi: "GET /v1/properties/{property_id}/tax-assessments"
---

Read this account’s unexpired tax-assessment snapshot records for 1 credit. For NYC PLUTO properties, DOF tax-roll assessed figures; for address-composite properties (prop_usproperty_), the matched county assessor assessed/market snapshot where published. Tax-roll figures are not tax bills, sale prices or AVMs.

<Note>Check [live capabilities](https://realtycrawl.dev/v1/meta/capabilities) before calling this operation.</Note>
