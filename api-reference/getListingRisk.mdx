Read Zimmo’s literal flood and planning codes from your account’s saved observation. Each entry preserves its source type, reported status and any source destination code. verification remains source_reported_unverified.

This is not an official hazard map, insurance assessment, legal opinion or permission to develop. A cadastral-income figure belongs to property facts and is not a tax bill. One credit per successful retained read; no fresh source request or retention renewal. Missing sections return SOURCE_DATA_UNAVAILABLE.
