---
title: "Read latest recorded one-family sale"
openapi: "GET /v1/properties/{property_id}/transactions"
---

Read this account’s unexpired property transaction records for 1 credit. For NYC PLUTO, the newest source-reported one-family sale entry; for address-composite properties (prop_usproperty_), the assessor-reported last sale where published. Not full title or transaction history coverage.

<Note>Check [live capabilities](https://realtycrawl.dev/v1/meta/capabilities) before calling this operation.</Note>
