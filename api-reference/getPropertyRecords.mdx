---
title: "Read a property-record snapshot"
openapi: "GET /v1/properties/{property_id}/records"
---

Read this account’s unexpired property records for 1 credit. For NYC PLUTO properties, parcel records and recorded sale context; for address-composite properties (prop_usproperty_), county assessor record, recorder deed/mortgage/lien index documents and portal observation records, each with source provenance and stated limitations. Recorded documents are filed-instrument index rows, not a lien search or verified title.

<Note>Check [live capabilities](https://realtycrawl.dev/v1/meta/capabilities) before calling this operation.</Note>
