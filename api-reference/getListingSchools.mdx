This Zillow section is documentation-backed beta, validated with saved source fixtures and offline tests; it is not fresh live acceptance. Resolve a Zillow URL or fetch a ZPID detail first, then use the returned listing ID. Missing sections return CAPABILITY_UNAVAILABLE; explicit empty sections remain empty.

Returns source-reported nearby schools. Assignment is unverified; an unspecified rating scale or distance unit stays null.

A successful retained read costs 1 credit. No fresh source request occurs. Preserve source provenance, observation times and DOCUMENTED_SOURCE_BETA warnings.
