The inventory covers 200 researched platforms and 43 defined API operations. This release includes 40 source adapters and 11 enabled operation IDs, including three metadata operations. Check live capabilities for current enablement.

## Verified sale-search adapters

Zillow: contiguous United States; location.kind=bbox and location.bbox=[west,south,east,north].

Redfin: United States; location.kind=postal_code, location.postal_code="78701", location.country="US".

Realtor.com: platform slug realtor; location.kind=text, location.query="Austin, TX", location.country="US".

Rightmove: Great Britain; location.kind=text, location.query="London", location.country="GB".

Idealista: Spain; location.kind=text, location.query="Madrid", location.country="ES".

Realtor.ca: realtor_ca, CA; Zoopla: zoopla, GB; realestate.com.au: realestate_au, AU; Property Finder: propertyfinder, AE. These use location.kind=text, location.query and the stated country.

Spitogatos: spitogatos, GR, location.kind=text; example query Kolonaki. Residential sale search only.

Square Yards: squareyards, IN; use location.kind=source_region, location.platform=squareyards and location.region_id=mumbai (the source city slug).

Hepsiemlak: hepsiemlak, TR; use source_region with platform=hepsiemlak and region_id=istanbul (the source city slug).

MercadoLibre: mercadolibre, AR; apartment sale search only. Use source_region with platform=mercadolibre and region_id=bsas-gba-sur/lomas-de-zamora, the path after departamentos/venta/ in the source search URL.

OneRoof: oneroof, NZ; house sale search. Use source_region with platform=oneroof and region_id=auckland-city-auckland-225, the district slug and ID.

99.co: 99co, SG; use source_region with platform=99co and region_id=singapore for island-wide residential sale search.

Habitaclia: habitaclia, ES; Fotocasa: fotocasa, ES; Argenprop: argenprop, AR (apartments); Nigeria Property Centre: nigeriapropertycentre, NG (houses); Daft: daft, IE. Use location.kind=text with location.query and the stated country.

realestate.co.nz: realestate_nz, NZ; source_region with region_id=auckland. Sale results can include rural properties. HTTP-only source photos are omitted; auction and negotiation text remain non-numeric.

Mubawab: mubawab, MA; apartment sales, source_region with region_id=casablanca. Zimmo: zimmo, BE; source_region with region_id=gent-9000 (locality and postcode).

Lamudi: lamudi, PH; nationwide house sales, source_region with region_id=philippines. Private Property: privateproperty, ZA; source_region with region_id=south-africa/1 (the path after for-sale/).

FincaRaíz: fincaraiz, CO; apartment sales, source_region with region_id=bogota (city slug). MyHome: myhome, IE; source_region with region_id=dublin (county slug). PropertyPro: propertypro, NG; house sales, source_region with region_id=lagos (state slug). PropertyPro does not publish a separate native ID through this provider; the resource ID is based on the canonical listing URL.

Homes.com: homes, US, text query Charlotte, NC. Centris: centris, CA (Quebec residential listings), text query Montreal. Searches expose the source search fields; richer listing details and agent modes are not enabled.

Pisos: pisos, ES, apartment sales; source_region with region_id=madrid_capital (city/province slug, with underscores). Immoweb: immoweb, BE, regular apartment sales nationwide; source_region with region_id=belgium. Both return locality only; unverified precise addresses and coarse Pisos map points are omitted. Immoweb may retrieve a minimum upstream batch of ten, but the API enforces the requested result limit.

Immowelt: immowelt, DE, text query Berlin. This is the source keyword search, not a strict municipal boundary: nearby or keyword-matching listings can appear. Only BUY records pass normalization. A hidden address suppresses the street and coordinates.

Boligsiden: boligsiden, DK, municipality-name text query Aarhus. Etuovi: etuovi, FI, residential-sale text query Helsinki. Danish and Finnish room counts are not bedroom counts. Boligsiden asking prices are separate from public valuations and mortgage estimates; Etuovi bidding prices remain non-numeric.

Immobiliare: immobiliare, IT; source_region with region_id=roma (the path after vendita-case/). Auction and bare-ownership records are excluded. Hidden prices remain unknown; precise addresses and coordinates require the source exact-location flag.

Otodom: otodom, PL; apartment sales. Use source_region with region_id=mazowieckie/warszawa/warszawa/warszawa (the full source location path, not a bare city). Returns locality only; room counts are not bedroom counts.

Bayut: bayut, AE; apartment sales. Use source_region with region_id=dubai. Public listing IDs differ from internal index IDs. Rooms represent bedrooms (zero means studio), and area is built area in square metres. Exact coordinates are omitted because address visibility is unverified. The provider may fetch a minimum of ten records; RealtyCrawl enforces the requested result limit.

Property24: property24, ZA; source_region with region_id=val-de-vie-estate/paarl/western-cape/11726 (suburb/city/province/numeric-ID path). Auctions and off-portal records are excluded. Erf size is land area, not building area. Currency is ZAR; location is locality only.

Cian: cian, RU; apartment sale text query Москва. Source results can include new-build and resale apartments. Hidden-address flags suppress precise location; localized room and area summaries are not converted into typed measurements. Layout images are excluded from photos. The provider can over-return records; the API still applies the requested limit.

For every source_region selector, set location.platform to the platform slug and location.country to the country above.

Every location selector above includes location.country. All adapters require transaction=sale. Start with limit=1. Only capability-advertised filters are accepted; source_region paths are not free-text geocoding.

## Shared operations

All 40 adapters support platform search, unified search, stored listing retrieval and stored media. Zillow supports canonical URL resolution and source-reported price history. Rightmove supports fresh native-ID lookup and canonical URL resolution. OneRoof supports stored open-home schedules in UTC. Stored observations belong to the requesting account and expire after 24 hours.

Source records retain their original currencies and area units. Hidden search prices, auction text, price ranges and ambiguous room counts are not converted into exact asking prices or bedroom counts.

## Unavailable coverage

The remaining 160 sources and 32 operation definitions are not enabled. Rentals, merged property records, valuations, dedicated agent/agency APIs, auction-event APIs, buildings, stays and async jobs require separate implementation and verification. Licensed MLS and public-record feeds need their own access agreements. BuyRentKenya and iProperty failed the latest capped tests; Casa.it returned no results. Other failed samples include Flatmates and Dubizzle Egypt.

Current excluded samples: Imobiliare.ro and Compass exceeded the synchronous deadline; Hemnet and Zolo returned no usable records. ImmoScout24 was interrupted by a client connection failure; Imovirtual did not complete successfully. Sahibinden returned an upstream error and MagicBricks returned no listings. These failures do not enable those sources.

## Understand completeness

Search results are bounded source observations, not complete inventories. Source order is preserved. A missing continuation cursor does not mean that every listing was collected. Source fees, run limits and provider availability can constrain results. Preserve warnings, source outcomes and completeness metadata.
